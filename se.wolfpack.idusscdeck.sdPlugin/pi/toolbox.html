Action

Install Idus SC Toolbox first. On Arch / CachyOS, paste this in a terminal:

sudo pacman -S --needed python-gobject gtk4
d=$(mktemp -d) && cd "$d" && for f in idus-sc-toolbox.py install-idus-sc-toolbox.sh idus-sc-toolbox.png; do curl -fsSLO "https://github.com/Idus/idus-sc-toolbox/releases/latest/download/$f"; done && bash install-idus-sc-toolbox.sh

Other distributions: install the GTK4 Python bindings (python-gobject / python3-gi and gtk4), then run the second line.

StarStrings works without it — pick it below.

⚠ = takes three presses. The channel matters for shaders and StarStrings.

StarStrings shows the game version the installed strings were made for and the install date, e.g. "4.10 · 8 Nov". Green dot = no newer release on GitHub, amber = a newer release exists or the strings are for an older patch.

What the actions do
Kill SC ⚠Force-stops Star Citizen, the RSI Launcher and Wine (wineserver) in the game folder — for a game that hangs.
Restart launcher ⚠Stops everything, then starts the RSI Launcher again with LUG's sc-launch.sh.
Patch / verify ⚠Like restart, but on the PATCH runner — for game updates and Verify. Needs patch mode in sc-launch.sh (see the Toolbox README).
Back upSaves keybinds and settings (the user folder and USER.cfg of every channel) plus sc-launch.sh to a dated backup.
Restore ⚠Puts back the newest backup. Only when the game is closed, and it takes a safety copy of the current state first.
Clear shadersDeletes the shader cache for the channel (game closed). The next launch takes longer while it rebuilds.
StarStringsBuilt in — works without Idus SC Toolbox. Downloads the newest StarStrings (MrKraken) into the channel, keeps the old file and adds g_language = english to user.cfg. Not installed yet? The first press installs it, then opens its guide and the game folder.
Fix windowsCentres the RSI Launcher and moves Star Citizen to the main screen (KDE).
