## Description (English, 250–1,500 characters)

```
Idus SC Deck puts the Star Citizen information you check most on your Stream Deck, in one consistent dark look with an orange tab that names each key's family.

TIME – clocks for every server region (US West, US East, EU, Asia, Australia, any city) and UTC with the date.
CZ – the Contested Zone executive hangar on one key: open or closed, countdown, next change and the five door lights.
STAT – RSI server status, your installed game version against the newest release notes, crowdfunding total and GPU memory.
LOG – live from your own Game.log: the region and shard you landed on, Armistice zone in or out, and 30K disconnects this session. Read on your PC only.
PLAY – starts the RSI Launcher and shows your session time.
TOOL – built-in tools: update StarStrings with one press (keeps your old file and adds the user.cfg line), back up and restore keybinds, clear shader caches, stop a hung game.

Requirements: Windows 10 or 11, Stream Deck 7.1 or newer, Star Citizen installed with the RSI Launcher. The VRAM view needs an NVIDIA card.

Made by Idus with AI assistance (Claude). Unofficial fan project, not affiliated with Cloud Imperium Games. Star Citizen is a registered trademark of Cloud Imperium Rights LLC.
```

## Data and privacy

No user data is collected and nothing is sent about the user. The plugin only reads public data: RSI's status page, RSI's
crowdfunding stats and Patch Notes forum, cztimer.com / exec.xyxyll.com for the Contested Zone timer, and GitHub for
StarStrings. Game.log and the game folder are read locally. No privacy policy is required for this, per Elgato's
submission guidelines (only when collecting user data).
